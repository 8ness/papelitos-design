# 5. MOVIMIENTO DEL HERO

Mantener el concepto de movimiento actualmente presente.

## Mariposas

Las mariposas deben tener movimiento suave y elegante.

Visualmente diseñarlas para permitir:

* flotación ligera
* desplazamiento vertical muy suave
* desplazamiento horizontal mínimo
* ligera rotación
* pequeñas variaciones de posición

No deben moverse rápidamente.

No quiero que distraigan del contenido.

---

## Estrellas de mar

Las estrellas de mar también pueden tener micro movimiento.

Diseñar pensando en:

* parallax muy sutil
* pequeña rotación
* desplazamiento mínimo con el scroll

El movimiento debe ser incluso más suave que el de las mariposas.

Debe sentirse integrada en la composición.

# 7. TRABAJOS SELECCIONADOS

Mantener los trabajos reales actualmente mostrados.

No reemplazar las imágenes ni inventar proyectos.

## Problema actual

Las tarjetas / previews de los trabajos están demasiado separadas entre sí.

Esto genera demasiado espacio vacío y hace que la sección pierda continuidad visual.

## Cambio solicitado

Acercar los proyectos entre sí.

Quiero que se sientan como una **galería editorial continua**, no como elementos aislados flotando con grandes espacios entre ellos.

Reducir:

* gaps verticales excesivos
* espacios blancos innecesarios
* separación entre columnas

Mantener suficiente aire para que no quede saturado.

---
